=== Overview

Generate html app running completely locally in browser to do the following

- User input financial data for single/widowed or married couple
- A set of adjustment sliders for varying future financial foundation variables (inflation, COLA adjustment)
- Show graph of future social security
- Produce charts to show income stacking trends in the future
- Produce IRRMA tier bars on income trend
- Show total income tax
- Show Taxable social security
- All numbers calculated in today's numbers to provide easy understanding with today's costs
- Save and restore user input and slider variable so user can make progress in multiple sessions

=== Today vs Future values

If a value is in a future year, use inflation rate to extrapolate for all other years.

When showing graphs, show all calculated values in today's $s. This is easier for user to understand

=== General Layout

An input column on the left (a pane for each person)
A output column showing the visualization graph sections
Both columns have independent vertical slider bar
This allows user to adjust input while seeing a particular graph of interest in a long multiple page display
